🔄 Xóa Cache Cũ & Tải Mới

📦 1. Service Worker (sw.js)

Lưu trữ Model ONNX 137MB & Voices vào CacheStorage. Biến web app thành PWA chạy offline 100% khi mất mạng.

⚙️ 2. Web Worker (tts-worker.js)

Chạy ONNX Runtime Web đa luồng (WASM SIMD) ngầm. Giữ Main Thread luôn đạt 60 FPS, không đơ lag khi sinh giọng.

🔊 3. Web Audio Streaming

Nhận sóng âm PCM từ Worker qua Zero-Copy ArrayBuffer. Đẩy ngay vào AudioContext phát tức thì.

Độ mượt Main UI Thread: 60 FPS (Mượt mà)
Chưa có bộ nhớ đệm (0 tệp)
Service Worker tải trước mô hình ONNX INT8 (137 MB) và các file vector giọng đọc vào Cache API của trình duyệt. Sau khi nạp, bạn có thể tắt mạng hoàn toàn và kiểm tra tính năng chạy độc lập.
